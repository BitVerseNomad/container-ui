# OpenPier 0.3.0

## What is new

1. The app is now called OpenPier. Your saved settings are kept. macOS sees it as a new app, so remove the old one from Applications by hand.
2. The Containers page is rebuilt. Containers with problems show first. Each container has one status dot and one plain word, such as Running or Stopped.
3. Each container has its own page, with six tabs: Logs, Stats, Settings, Folders, Network and History.
4. Back and forward work on every page.
5. Run and Compose projects open in side sheets. A Compose project shows its live logs.
6. The app picks its engine when it starts. One engine switcher replaces the old profile box.
7. Keyboard shortcuts are in one list. The same list drives the Help screen and the command palette.
8. The Containers page has a clear view for each of its states, such as loading, empty and engine stopped.

## How to install

1. Apple Silicon Mac: download the `.dmg` from this release, open it, and drag OpenPier to Applications.
2. The app is not signed by Apple. The first time you open it, go to System Settings, then Privacy & Security, and click **Open Anyway**. You only do this once.
3. Or run the one-line installer from the README ("Install in one line"). It also updates the app later.

The README has the full install steps.
